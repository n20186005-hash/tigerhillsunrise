# Tiger Hill Observatory / Sunrise Viewpoint

A single-page Astro 7 + Tailwind CSS v4 + TypeScript site for **Tiger Hill Observatory / Sunrise Viewpoint** in Darjeeling, West Bengal, India. Content language is Nepali (Devanagari) — the lingua franca of the Darjeeling hills — while all SEO signals (title, description, JSON-LD, OG, sitemap) carry the official English name plus the Hindi/Nepali aliases so the entity is unambiguous to Google.

## SEO entity binding

The single page is wired so that a Google crawl of `tigerhillsunrise.com` lands on a single coherent entity record:

- `<title>`, `<meta description>`, canonical, `hreflang ne + x-default`, OG (title, description, url, site_name, locale `ne_IN` + alternates `en_IN` / `hi_IN`, image + image:alt + image:width/height/type), Twitter card.
- A single JSON-LD `<script type="application/ld+json">` block with a 6-node `@graph`:
  1. `WebSite` — publisher
  2. `Organization` — `tigerhillsunrise.com` with 512×512 logo
  3. `WebPage` — `datePublished` + `dateModified 2026-09-10`, `primaryImageOfPage`
  4. `TouristAttraction` — `@id https://tigerhillsunrise.com/#attraction`, `name` + 4 `alternateName` (incl. Devanagari), `image`, `isAccessibleForFree`, full `PostalAddress` (street / locality / region / postalCode / IN), `geo`, `hasMap`, 5-link `sameAs` (Google Maps, darjeeling.gov.in, incredibleindia.gov.in, wbtourism.gov.in, en.wikipedia.org), `openingHoursSpecification` (Mo–Su 03:00–17:00), `aggregateRating 4.5/18354`, `touristType: Viewpoint, Observatory`, `containedInPlace: Senchal Wildlife Sanctuary`.
  5. `BreadcrumbList` — Home → Darjeeling, West Bengal → Tiger Hill Observatory / Sunrise Viewpoint
  6. `FAQPage` — 8 questions in Nepali (matches the visible FAQ)
- H1: `Tiger Hill Observatory / Sunrise Viewpoint` + Devanagari subtitle line.
- Four entity-bound `<h2>` nodes (each keeping the original poetic Nepali line as a `.kicker-np`/`.kicker-np-dark` subline, so the artistic copy is preserved):
  - `About Tiger Hill Observatory / Sunrise Viewpoint`
  - `History & Significance of Tiger Hill Observatory / Sunrise Viewpoint`
  - `Location & How to Visit Tiger Hill in Darjeeling`
  - `Landmarks & Attractions Around Tiger Hill`
- First-paragraph equivalence statement + visible breadcrumb (`Tiger Hill Observatory / Sunrise Viewpoint → Darjeeling → West Bengal → India`).
- Image `<img alt>` text on every body photo binds the figure to the entity.
- `Sources & Further Reading` section with 6 official sources (darjeeling.gov.in, incredibleindia.gov.in, wbtourism.gov.in, UNESCO DHR listing, Wikipedia, Google Maps listing) + last-updated stamp + CC photo attributions — this is the E-E-A-T footprint.

## PWA

- `public/site.webmanifest` — `name`, `short_name`, `description`, `id`, `start_url: /`, `scope: /`, `lang: ne`, `display: standalone`, `theme_color #10182d`, `background_color #f3eee5`, 6 icons (SVG any, 32/180, 192, 512, 512 maskable).
- `public/sw.js` — versioned cache (`ths-2026-09-10`), network-first for navigations with `/` offline fallback, cache-first for same-origin static assets, cross-origin skipped.
- Icons generated by `scripts/make-pwa-icons.mjs` (Node stdlib only — `zlib` + raw RGBA + minimal PNG encoder). Run with `npm run pwa:icons`.
- Service worker registered from `index.astro` (skipped on `localhost` / `127.0.0.1`).

## Domain configuration

`site` lives in **one place**: `astro.config.mjs`. Set to `https://tigerhillsunrise.com`. Every consumer (canonical, `og:url`, Twitter image, JSON-LD `url`/`@id`, sitemap, og:image absolute URL) reads from there or from a manually constructed `new URL(path, SITE)`.

## Run

```bash
npm install
npm run pwa:icons   # optional — only when the manifest icon set changes
npm run check       # astro check
npm run build       # writes dist/
npm run preview     # local preview
npm run deploy      # wrangler deploy (Cloudflare Workers static assets)
```

## Content notes

Vehicle access, coupons/cut-offs, parking and the observatory-deck ticket change with the season and local orders. The site treats them as variable information, recommends confirming locally the night before, and links to the official sources for current rules.
